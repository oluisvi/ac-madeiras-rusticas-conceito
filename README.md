# AC Madeiras Rústicas — conceito de experiência digital

Protótipo mobile-first de uma página com três direções visuais alternáveis: **Origem**, **Oficina** e **Matéria**. Inclui referências visuais filtráveis, percurso de projeto sob medida, aviso de não envio, localização e mensagens de consulta pré-preenchidas para o WhatsApp.

## Limites de conteúdo

As imagens foram geradas como ilustrações para este conceito e não representam peças reais ou disponíveis da AC. Medidas, materiais e disponibilidade aparecem como informações a confirmar. Endereço e telefone foram obtidos de fontes públicas citadas no relatório de prospecção e precisam de validação da AC antes de uma publicação comercial definitiva.

## Arquivos

- `index.html` — estrutura e metadados.
- `styles.css` — três sistemas visuais e comportamento responsivo.
- `script.js` — alternância, filtros, mensagens e motion progressivo.
- `assets/` — ilustrações conceituais otimizadas.
- `BRIEF_DO_PROJETO.md` — discovery, limites e mensagens preparadas.

## Publicação

Site estático, sem dependências de build. O GitHub Pages pode servir os arquivos diretamente da raiz.
